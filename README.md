# Школа «Горизонт» — CRM + лендинг

Демо-проект для частной школы: публичный сайт и CRM для администрации. Все данные — мокап
(сгенерированы в коде), изменения сохраняются в `localStorage` браузера.

Демо: https://a1ikhan.github.io/school-crm/

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173.

- `/` — лендинг школы
- `/login` — вход в CRM (демо, данные уже заполнены)
- `/crm` — CRM

## Что есть

**Лендинг:** hero, преимущества, программы (1–4, 5–9, 10–11 классы), распорядок дня, педагоги,
стоимость, отзывы, FAQ, форма записи. Заявка с формы сразу появляется в CRM в разделе «Заявки».

**CRM:**
- **Дашборд** — ученики, поступления за месяц, задолженность, заявки, график оплат, воронка набора
- **Заявки** — канбан с перетаскиванием и список; создание, редактирование, «Зачислить в ученики»
- **Ученики** — поиск, фильтры, сортировка, экспорт CSV; карточка ученика с оценками и оплатами
- **Классы** — наполняемость, классный руководитель, средний балл, долг
- **Педагоги** — карточки с нагрузкой и контактами
- **Расписание** — по классу или по педагогу
- **Оплаты** — счета по месяцам, приём оплаты, экспорт CSV

Кнопка «Сбросить демо-данные» в меню CRM возвращает исходный мокап.

## Деплой

При пуше в `main` или `claude/ecstatic-franklin-ifuu45` GitHub Actions собирает проект
и публикует его на GitHub Pages (`.github/workflows/deploy.yml`). В настройках репозитория
(Settings → Pages) источник должен быть «GitHub Actions».

## Стек

React 19, TypeScript, Vite, Tailwind CSS 4, React Router, Recharts, lucide-react.

## Структура

```
src/
  data/        типы, константы, генератор мокап-данных
  store/       состояние приложения (React context + localStorage)
  components/  общие UI-компоненты
  landing/     лендинг
  crm/         layout, вход и страницы CRM
```

Валюта и название школы задаются в `src/data/constants.ts`.
